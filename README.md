## 🔬 Core Focus Areas
- 🧠 **Large Language Models (LLMs)**: Mixture-of-Experts (MoE), long-context attention, reasoning distillation, mathematical RL.
- 🤖 **Humanoid Robotics & Embodied AI**: Bipedal dynamic balancing, sim-to-real locomotion, dexterous end-effector manipulation.
- 👁️ **Computer Vision & Multimodal AI**: 3D Gaussian Splatting, zero-shot open-vocabulary segmentation, neural radiance fields.
- ⚡ **AI Hardware & Neuromorphic Processors**: Compute-in-memory architecture, RISC-V acceleration, ultra-low-latency edge vision.
